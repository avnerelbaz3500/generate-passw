# Password Generator (Private)

## Description

This project is a web application that allows you to generate secure and customized passwords based on your needs. Following ANSI rules, it offers flexible options to create strong passwords or memorable passphrases.

The tool is designed to enhance the security of your online accounts or sensitive files by generating identifiers that follow best practices.

---

## Features

- **Password generation with customizable settings**:
  - Configurable length.
  - Option to include or exclude uppercase letters, lowercase letters, numbers, and special characters.

- **Creation of passphrases based on random words**:
  - Configure the number of words.
  - Add custom separators (space, dash, etc.).

- **Advanced options to meet specific requirements**:
  - Minimum required for each character type.
  - Built-in strength indicator.
